一、意图和指令说明
1. 指令类型：音量控制
意图: volume_control
1.1 降低音量
指令名称：降低音量
指令结构化:
{
	"intent": "volume_control",
	"value": "speaker",
	"params": {
		"volume": "down"
	}
}
prompt 语料示例: 音量调低一些，声音小一点，声音太大了，小声点，说话轻一点，声音收一收，太吵了，声音压低一点，降低点分贝

1.2 提高音量
指令名称：提高音量
指令结构化:
{
	"intent": "volume_control",
	"value": "speaker",
	"params": {
		"volume": "up"
	}
}
prompt 语料示例: 音量调高一些，声音大点，声音有点小，大点声，声音响一点，提高点分贝

1.3 静音

	"intent": "volume_control",
	"value": "speaker",
	"params": {
		"volume": "mute"
	}
}
prompt 语料示例: 静音，音量调到最低，音量关掉，声音关掉，安静

二、任务说明
端侧意图识别和指令解析任务，可能会包含两类：单任务和多任务，同时端侧算法针对的是简单以及稍微复杂一些的意图和指令解析任务，要求高准确率，宁可错过也不漏判、错判等等，所以复杂的单任务和多任务可以交给后端大模型来判断，在端侧直接返回"unknow"即可
下面是返回 json 结构化的数据格式
1. 单任务
用户输入“声音调整到 70%”，返回如下:
{
	"query_type": "single_task",
	"tasks": [
	    "user_input": "声音调整到 70%",
	    {
			"intent": "volume_control",
			"value": "speaker",
			"params": {
				"volume": "70"
			}
		}
	]
}
2. 多任务
用户输入"到客厅打开投影仪", 包含导航到客厅和打开投影仪两个任务指令，返回结果如下
{
    "query_type"："multi_task",
    "tasks": [
        {
            "user_input":"到客厅",
            "intent": "robot_control", 
            "value":"nav",
            "params":{
                "place":"客厅"
            }
        },
        {
            "user_input":"打开投影仪"，
            "intent": "projector_control", 
            "value": "projector",
            "params":{
                "control": "open"
            }
        }
    ]
}
